# Simple Interest Calculator

## Overview

The Simple Interest Calculator is a simple web application developed using HTML, CSS, and JavaScript. It calculates the simple interest and total amount based on the principal amount, rate of interest, and time entered by the user.

## Purpose

The purpose of this project is to provide an easy-to-use calculator for calculating simple interest quickly and accurately.

## Formula

The simple interest is calculated using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

The total amount is calculated as:

**Total Amount = Principal + Simple Interest**

Where:

* **Principal** = Initial amount of money
* **Rate** = Rate of interest per year
* **Time** = Time period in years

## How It Works

1. Enter the principal amount.
2. Enter the rate of interest.
3. Enter the time period in years.
4. Click the **Calculate** button.
5. The application calculates and displays the simple interest and total amount.

## Technologies Used

* HTML
* CSS
* JavaScript

## Example

For example, if:

* Principal = 10,000
* Rate = 5%
* Time = 2 years

Then:

**Simple Interest = (10000 × 5 × 2) / 100 = 1000**

**Total Amount = 10000 + 1000 = 11000**

Therefore, the simple interest is **1,000** and the total amount is **11,000**.
